# Document Request System - Guidelines

## Overview

The MinSU DocuReg system now supports three major documents with standardized 6-working-day processing times and mandatory appointment scheduling for document pickup.

## Supported Documents

The system now handles the following three major document transactions:

### 1. **Transcript of Records**
- **Purpose**: Official academic transcripts showing grades and courses completed
- **Usage**: Job applications, further studies, scholarship applications
- **Processing Time**: 6 working days
- **Appointment Required**: Yes (for pickup)

### 2. **Certificate of Transfer Credentials and Academic Records**
- **Purpose**: Official transfer credential certificate with complete academic history
- **Usage**: Transferring to another institution, employment verification
- **Processing Time**: 6 working days
- **Appointment Required**: Yes (for pickup)

### 3. **Request for Second Copy of Diploma**
- **Purpose**: Replacement diploma copy for lost or damaged original
- **Usage**: Personal records, employment requirements
- **Processing Time**: 6 working days
- **Appointment Required**: Yes (for pickup)

## Processing Timeline

### For Students:
1. **Submit Request** - Students fill out the document request form
2. **Processing Period** - System automatically sets expected completion to 6 working days
3. **Schedule Appointment** - Once notified that document is ready, student schedules pickup appointment
4. **Pickup** - Student attends appointment to receive the document

### For Registrars:
1. **Receive Request** - New request appears in pending requests
2. **Process Document** - Prepare document over the 6-working-day period
3. **Mark Ready** - Update status to "Ready" when document is prepared
4. **Schedule Appointment** - Create appointment for student to pickup
5. **Complete Transaction** - Update status to "Completed" after pickup

## Working Days Definition

The system calculates 6 working days excluding:
- **Saturdays**
- **Sundays**
- *Note: Public holidays should be manually managed by registrars*

## Expected Completion Date

When a student submits a document request:
- The system automatically calculates the **Expected Completion Date** (6 working days from submission)
- This date is displayed on the student's request details page
- Students can see this timeline to plan accordingly

## Appointment Scheduling

### Important Notes:
- ✅ All documents **require appointment scheduling** for pickup
- ✅ Appointments can only be scheduled after the 6-working-day processing period
- ✅ Registrars have guidelines to schedule appointments appropriately
- ✅ Students receive notifications when their document is ready and can book appointments

### Booking an Appointment:
1. Student views their request details
2. Once document is marked "Ready", they can schedule an appointment
3. Registrar coordinates available time slots
4. Confirmation is sent to student's email

## Best Practices

### For Students:
1. Submit requests early if you have deadline requirements
2. Check your email regularly for status updates
3. Schedule appointments as soon as notified the document is ready
4. Arrive 5-10 minutes early to appointments
5. Keep copies of your request confirmation

### For Registrars:
1. Process documents systematically throughout the 6-working-day period
2. Update request status regularly
3. Schedule appointments only after/near completion of processing
4. Send email notifications when documents are ready
5. Maintain accurate records of completion dates

## Error Handling

If a student tries to:
- Request an unsupported document type → System will reject with error message
- Submit duplicate requests too quickly → Consider warning/limiting
- Schedule appointment before processing is done → System may restrict or warn
